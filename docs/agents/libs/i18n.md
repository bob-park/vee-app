# i18n

> Frontend strings live in `src/shared/i18n/en.ts` (the base `Dict`) and `ko.ts` (typed `: Dict`, so a missing key fails `yarn typecheck`). Components read them with `const { t } = useI18n()`. Native labels (tray menu) live in `src-tauri/src/app/i18n.rs`. The preference (`system` | `en` | `ko`) is the `locale` key in SQLite.

## Adding text

1. Add the key to `en.ts`, nested by area (`settings`, `filters`, `kinds`, `whatsNew`, …). Use a function for interpolation: `chars: (n: number) => \`${n.toLocaleString('en')} chars\``.
2. Add the same key to `ko.ts`. `yarn typecheck` fails until you do.
3. In the component: `const { t } = useI18n();` (under `// hooks`), then `t.area.key`.

Never hardcode user-visible text in a component. Language names in the language picker stay in their own language (`한국어`, `English`). Relative times use `relativeTime(ms, locale)` from `src/shared/i18n`.

## Resolution

- `resolveLocale(pref, navigator.language)` (`src/shared/i18n/locale.ts`, unit-tested): `system` → `ko` if the OS language starts with `ko`, otherwise `en`.
- Rust uses the same rule in `app::i18n::resolve_locale`, reading the OS language through `sys-locale`.
- `I18nProvider` sets `<html lang>` and listens for `settings://changed`. Rust's `set_setting` rebuilds the tray menu when `locale` changes.

## Native labels

`app/i18n.rs` holds a `Labels` struct per language (`labels(locale)`). When you add a tray item, add its label to both languages and build it from `labels(resolve_locale(…))` in `tray.rs`. Native window titles stay `Vee`. The macOS Full Disk Access prompt (`app/disk_access.rs`) keeps its ko/en text inline; put new native dialog text in `Labels` instead. The DB-open failure dialog in `lib.rs` is English-only (it runs before settings can be read).

## Adding a language

1. `src/shared/i18n/<code>.ts` typed `: Dict`. Register it in `dicts` (`index.ts`) and the `Locale` type (`locale.ts`).
2. Add it to the `locale` union in `settings.dto.ts` and to the language `Segmented` in `SettingsApp`.
3. Rust: allow it in `settings::validate`, add a `Labels` set and a `resolve_locale` arm (`app/i18n.rs`) and the Full Disk Access prompt text, with tests.
