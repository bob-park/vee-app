# 스크린 캡처·녹화 포인터 아이콘 교체 (짧은 설계)

## 의도

캡처 오버레이의 창 선택 모드 포인터를 한눈에 "캡처" / "녹화"로 읽히는 모던한 아이콘으로 바꾼다. Windows 고배율 화면에서 포인터가 너무 작게 보이는 문제도 함께 고친다.

## 범위

- 대상: `src/app/globals.css`의 `cursor-camera`(캡처 창 선택), `cursor-record`(녹화 창 선택) 두 개.
- 비대상: 영역 드래그 모드의 `cursor-crosshair`(OS 기본 십자선 유지), 그 밖의 커서.
- 실패로 보는 경우: 밝은 배경·어두운 배경·사진 배경 중 어디서든 포인터가 묻혀 보이는 경우, 또는 Windows에서 화면 가장자리 근처에서 기본 포인터로 바뀌는 경우.

## 디자인 (사용자 선택: A · 앱 아이콘형 배지)

- 32×32, 둥근 사각 타일(`rx=9`)에 흰 2px 테두리를 둘러 어떤 배경에서도 윤곽이 보이게 한다.
- 캡처: 보라 `#7132f5` 타일 + 흰 카메라 기호(렌즈는 타일 색으로 뚫음).
- 녹화: 빨강 `#e5283c` 타일 + 흰 링과 가운데 흰 점(녹화 버튼).
- 핫스팟은 가운데 `16 16`, 폴백은 지금처럼 `pointer`.
- 색은 라이트 테마의 `--color-primary`와 `--vee-rec` 값을 쓴다. data URL 안에서는 CSS 변수를 쓸 수 없으므로 값을 직접 적는다. 포인터는 테마와 관계없이 같은 모양이다.
- 시안: `.superpowers/brainstorm/…/content/cursors.html`의 A.

## 접근 방법

1. **CSS만 수정 (선택)**: 32px SVG를 `image-set()`으로 1x와 2x(64px 래스터 크기)로 함께 지정한다. 고배율 화면에서 선명하게 제 크기로 보인다. 크기는 32 CSS px가 상한이다. WebView2(Chromium)는 32px보다 큰 커서가 가장자리에 걸리면 숨긴다.
2. 포인터를 DOM에 SVG로 직접 그리기: 크기 제한은 없지만 한 프레임 늦게 따라오고 코드가 는다. 1번으로도 부족할 때 넘어갈 대안이다.
3. Rust에서 네이티브 OS 커서 설정: WebView2가 커서를 다시 덮어써 충돌한다. 제외.

1번으로 고친 뒤 Windows에서 여전히 작으면 2번으로 간다.

## 구현 메모 (빌더 몫)

- `image-set()` 커서 지원과 문법(`-webkit-` 접두사 필요 여부, WKWebView와 WebView2 모두)은 구현 전에 최신 문서로 확인한다. 지원하지 않는 쪽을 위해 일반 `url()` 선언을 앞에 둔다.
- 사용자에게 보이는 문구는 없으므로 i18n 변경도 없다.
- 확인: `yarn tauri dev`로 macOS에서 두 모드 포인터를 눈으로 확인한다(라이트/다크 배경). Windows 실기기 확인은 사용자에게 요청한다. 네 가지 체크(cargo test / yarn test / typecheck / lint)를 통과해야 한다.
