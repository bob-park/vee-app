# 피사체 선택: 둘러 그리기(고리) 추가 — 짧은 설계

- 날짜: 2026-11-01
- 브랜치: `feature/editor-bg-brush-subject` (같은 PR에 포함)
- 앞선 설계: [2026-10-31-editor-bg-brush-subject-design.md](./2026-10-31-editor-bg-brush-subject-design.md)
- 목업: `.superpowers/brainstorm/57117-1793456813/content/subject-lasso.html` (A안 채택)

## 왜

갤럭시 휴대폰처럼, 대상을 대충 둘러 그려서 고르고 싶다. 클릭 선택은 그대로 두고 함께 쓴다. 고리로 대략 고른 뒤 클릭(＋)과 ⌥클릭(−)으로 다듬는다.

## 목표 / 비목표 / 실패 조건

- **목표:** 피사체 선택 도구 하나 안에서, 드래그하면 고리가 그려지고 짧게 누르면 지금처럼 클릭이 된다. 모드 전환은 없다(A안).
- **비목표:** 고리를 여러 개 합치는 것(마지막 고리 하나만 쓴다), 직선 다각형 그리기, 사각형 도구 따로 두기, 새 모델.
- **실패 조건:**
  - 클릭하려다 살짝 밀린 손이 고리로 잡힌다.
  - 고리 밖에 있는 다른 물체가 함께 선택된다.
  - 고리를 그릴 때마다 이미지를 다시 분석한다(인코더 재실행).

## 접근 방법

| | 방법 | 트레이드오프 |
|---|---|---|
| **1 (채택)** | 고리를 감싸는 사각형을 SAM 박스 프롬프트로 넘기고, 결과를 고리를 조금 넓힌 경계로 자른다 | SAM이 가장 잘하는 입력이고 임베딩도 재사용된다. 고리를 대상에 바짝 그리면 잘릴 수 있어서 아래 예외를 둔다. |
| 2 | 고리 안에 점을 자동으로 찍어 넘기기 | 점이 배경에 떨어지면 배경까지 선택되어 결과가 들쭉날쭉하다. |
| 3 | SAM 없이 고리 모양 그대로 따내기 | 대충 그린 선이 그대로 경계가 된다. "알아서 대상을 고르는" 동작이 아니다. |

사용자는 1을 골랐다.

## 정해진 것

- **입력 구분 (A안):** 포인터를 누른 뒤 화면에서 **8px 이상** 움직이면 고리, 그보다 적게 움직이고 떼면 클릭(⌥는 빼기)으로 처리한다. 고리는 손을 떼면 자동으로 닫힌다. 감싸는 사각형이 너무 작은 고리(긴 변 8 화면 px 미만)는 클릭으로 처리한다.
- **고리는 하나:** 다시 그리면 앞의 고리를 대체한다. SAM은 박스를 하나만 받는다. 점은 그대로 유지한다.
- **⌘Z:** 마지막에 넣은 것(점 하나 또는 고리 하나)을 되돌린다. 고리를 되돌리면 그 전 고리가 있었다면 그 고리로 돌아간다. 입력 순서를 기록해 두는 방식이다.
- **wire 형식:** `subject` 단계에 고리를 옵션으로 추가한다. `{ type: 'subject', points: SubjectPoint[], lasso?: [number, number][] }`. Rust는 `lasso: Option<Vec<[u32; 2]>>`이고, 값이 없으면 직렬화에서 빠진다. 그래서 기존 `{type,points}` 형식도 그대로 읽힌다. 좌표 규칙은 점과 같다(그 단계가 적용되는 이미지의 원본 해상도 px, 정수). 점과 고리가 **둘 다 비어 있을 때만** `InvalidInput`이다. 고리 점은 브러시처럼 솎아 낸다(`thinPoints`).
- **SAM 입력:** 고리를 감싸는 사각형의 두 모서리를 rembg 방식 그대로 넘긴다(라벨 2 = 왼쪽 위, 3 = 오른쪽 아래, 점과 같은 `scale` 적용). 클릭 점(1/0)을 함께 넣고, 맨 끝에 (0,0)/−1 패드를 붙인다. 임베딩 키는 지금과 같아서 고리를 그려도 인코더는 다시 돌지 않는다.
- **결과 자르기:**
  - 고리 다각형을 일정 폭만큼 넓힌 영역 **밖**의 알파는 0으로 만든다. 넓히는 폭은 이미지 긴 변의 2%, 최소 8px이다(정확한 값은 빌더가 정한다).
  - **예외:** `keep` 점이 하나라도 고리(넓히기 전) 밖에 있으면 자르지 않는다. 사용자가 고리 밖 부분을 일부러 더한 것이기 때문이다.
  - 알파만 바꾸고, 알파를 덮어쓰는 규칙(앞선 설계 5.3)은 그대로다.
- **표시:** 그린 고리는 보라 점선(`--color-primary`)과 아주 옅은 채움으로 이미지 위에 남긴다. 초기화하거나 적용하거나 다시 그리면 바뀐다. 그리는 동안의 선은 지연 없이 바로 그린다.
- **문구:** 힌트를 "대상을 둘러 그리거나 클릭하세요 · ⌥클릭으로 빼기"로 바꾼다(en: "Circle or click what to keep · ⌥-click to remove", Windows는 `Alt+`). 두 사전 모두 `src/shared/i18n/{en,ko}.ts`에 둔다.
- **메모리:** 바뀌는 것이 없다. 고리 데이터는 좌표 몇백 개다.

## 빌더에게 맡기는 것

- 다각형 래스터화와 넓히기 구현(거리 기반, 또는 다각형 채우기 후 팽창), 넓히는 폭 상수.
- 고리 점을 솎아 내는 간격.
- 입력 순서 기록을 어디에 둘지(프론트 상태로 충분하다).

## 테스트

- **Rust:**
  - `lasso` serde 왕복과 `lasso` 없는 기존 형식 읽기
  - 점과 고리가 모두 비면 `InvalidInput`
  - 박스 프롬프트 좌표·라벨 변환(순수 함수)
  - 자르기: 넓힌 고리 밖은 알파 0, 안은 유지. `keep` 점이 고리 밖에 있으면 자르지 않음
- **TS:** 드래그/클릭 판별 함수(8px 임계값), ⌘Z 입력 순서 되돌리기 함수.
- 네 가지 검사 통과. 화면 확인은 개발용 identifier로 사용자와 함께 한다.
