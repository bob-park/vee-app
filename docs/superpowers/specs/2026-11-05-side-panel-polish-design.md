# 좌우 패널 다듬기 설계 (짧은 설계)

브랜치: `feature/side-panel-polish`

## 의도

패널을 왼쪽/오른쪽에 붙였을 때 생기는 두 버그를 고치고, "좌우 패널을 더 좁게 쓰고 싶다"는 피드백을 반영한다.

## 목표

1. **패널 크기 초기화 응답없음 수정**: 원인은 `reset_panel_size`(`src-tauri/src/app/window.rs`)의 이중 잠금이다. `settings::set_raw(&db.lock(), stored_position(app)…)` 한 줄에서 DB 잠금을 잡은 채로 `stored_position()`이 같은 `std::Mutex`를 다시 잠가 메인 스레드가 멈춘다. 코드상으로는 하단 패널에서도, Windows에서도 똑같이 멈춘다. 위치를 먼저 읽고 그다음에 잠그도록 바꾼다. 같은 패턴의 이중 잠금이 다른 곳에도 있는지 확인한다.
2. **좌우 패널 툴바 3줄**: `검색` / `필터` / `[새 버전] ··· [고정][설정]`. 3줄은 `justify-between`으로 배치한다. 새 버전이 없으면 고정·설정 버튼만 오른쪽에 붙는다.
3. **업데이트 확인 말풍선 (A안)**: 좌우 패널에서는 버튼 왼쪽 끝에 맞춰 오른쪽으로 펼친다(`left-0`, `origin-top-left`). 폭은 패널 안쪽 폭을 넘지 않는다. 하단·상단 패널은 지금 그대로다.
4. **좌우 패널 최소 폭 340pt → 260pt**: `PANEL_MIN_WIDTH`.
5. **폭에 따라 바뀌는 필터**: 툴바 폭이 글자 탭 5개가 들어가는 폭(약 300px)보다 좁으면 아이콘만 보인다. 아이콘에 마우스를 올리면 이름이 뜨고, 버튼에는 `aria-label`이 붙는다. 선택된 탭을 보라색 알약이 따라가는 지금 애니메이션은 유지한다.
6. **고정 버튼 아이콘**: 📌 느낌의 빨간 압정 SVG로 바꾼다. 색은 라이트·다크 토큰으로 둔다. 누를 때 나오는 압정 애니메이션(`animate-pin-drop`/`pin-pull`)은 그대로 둔다.

## 비목표

- 하단·상단 패널의 툴바 레이아웃 변경.
- 필터 종류나 동작 변경.
- 좌우 패널의 기본 폭(화면 폭의 25%) 변경.

## 접근 방식

| 항목 | 고려한 방법 | 고른 방법 / 이유 |
|---|---|---|
| 툴바 3줄 | ① 기존 `in-data-side:` CSS 변형 ② 좌우용 JSX를 따로 렌더링 | ①. 마크업 하나를 유지하고, 하단 레이아웃에 영향이 없다. |
| 반응형 필터 | ① Tailwind 4 container query(`@container`) ② ResizeObserver로 폭을 재서 상태로 처리 | ①. CSS만으로 처리되고, 드래그로 크기를 바꾸는 중에도 즉시 반영되며 리렌더링이 없다. |
| 말풍선 위치 | A: 버튼 왼쪽에 맞춤 / B: 줄 폭만큼 펼침 / C: 3줄을 확인 창으로 교체 | A (사용자 선택). |
| 좁은 폭 필터 | 1: 아이콘만 / 2: 선택된 탭만 이름 표시 / 3: 드롭다운 | 1 (사용자 선택). 넓을 때는 지금의 글자 탭을 유지한다. |
| 고정 아이콘 | 📌 이모지 / SVG | SVG (사용자 선택). 이모지는 OS마다 그림이 다르다. |

## 제약

- 색은 `src/app/globals.css`에만 둔다. 새 토큰은 라이트·다크 양쪽 값을 넣는다.
- 필터 아이콘은 인라인 SVG로 넣는다(Lucide, ISC). 의존성은 추가하지 않는다.
- 사용자에게 보이는 문구는 `src/shared/i18n/{en,ko}.ts`에 둔다. 이번 작업에서는 기존 `filters` 문구를 툴팁과 `aria-label`에 재사용한다.
- DOM 훅 클래스 `update`는 유지한다.
- `pinsThatFit`(`src/utils/panelEdge.ts`)의 고정 높이(`CHROME = 116`)는 툴바가 3줄이 되면 다시 재야 한다.

## 구현하는 사람이 정할 것 (내가 정함)

- 반응형 전환 경계값: ko/en 중 더 긴 글자 탭 행이 실제로 들어가는 폭을 재서 정한다.
- 압정 SVG의 정확한 모양과 토큰 이름(`--vee-pin` 등).
- 아이콘 모드의 탭 크기. 클릭 영역은 지금 탭 높이보다 작아지지 않게 한다.

## 검증

- `cargo test --manifest-path src-tauri/Cargo.toml --lib`, `yarn test`, `yarn typecheck`, `yarn lint`
- `yarn tauri dev`로 좌우·하단 패널, 라이트/다크, 한국어/English를 확인한다. 패널 크기 초기화가 멈추지 않는지, 260pt 폭에서 업데이트 말풍선이 패널 안에 머무는지 본다.
