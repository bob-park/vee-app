# 캡처/녹화 "창" 모드 다듬기 — 설계

## 의도

화면 캡처·녹화 오버레이의 "창" 모드에서 거슬리는 세 가지를 다듬는다.

1. 다른 창에 가려진 창을 가리킬 때, 파란 틴트가 앞 창의 둥근 모서리를 따르지 않고 각지게 잘린다.
2. 바탕화면을 클릭하면 아무 반응이 없다. 거기서는 캡처나 녹화를 할 수 없다는 걸 알려 줘야 한다.
3. 창 선택 커서를 더 재미있고 현대적인 모양으로 바꾼다. 바탕화면 위에서는 "선택 불가" 커서를 보여 준다.

## 목표 / 비목표

- 목표: 위 세 가지를 macOS와 Windows, 캡처와 녹화 모두에 적용한다.
- 비목표: 영역(드래그) 모드의 커서와 동작, 기존 앱 토스트 창, 창 목록을 수집하는 Rust 코드는 바꾸지 않는다.

## 접근 방식

| 항목 | 검토한 방법 | 선택 |
| ---- | ----------- | ---- |
| 모서리 | 앞 창 전체를 둥근 사각형으로 마스킹하는 것 하나뿐 | 그대로 |
| 토스트 | A. 오버레이 안의 유리 알림 / B. 기존 토스트 창을 오버레이 위 레벨로 올리기 | **A**. 사용자가 보고 있는 오버레이 안에서 뜨고 React만 바꾸면 된다. B는 Rust 쪽 창 레벨과 위치 계산을 손봐야 하고, 다른 토스트에도 영향이 간다 |
| 커서 | A Aurora Orb / B Viewfinder / C Pointer+Badge / D Tilted Sticker | **D** (사용자 선택) |

## 설계

### 1. 겹친 창 모서리

- `coveredParts`(`src/utils/captureSelection.ts`)는 겹친 부분의 교집합 대신 **겹치는 앞 창의 사각형 전체**를 돌려준다.
- `CaptureApp`의 `tint-visible` 마스크는 그 사각형들을 `WINDOW_RADIUS` 둥근 모서리로 그린다. 틴트 사각형 밖으로 나간 부분은 마스크가 자연히 잘라 낸다.
- 단위 테스트(`node:test`)는 기존 `coveredParts` 테스트를 새 동작에 맞게 고친다.

### 2. 바탕화면 클릭 알림

- 창 모드에서 아무 창도 고르지 않은 상태(`!windowPicked`)일 때 클릭한 곳에 창이 없으면(`windowAt`이 null) 오버레이 안에 알림을 띄운다.
- 모양은 `.glass` + `bg-glass-float`를 쓴 작은 알림이고, 캡처 툴바 바로 위 가운데에 놓는다. 1.5초 뒤 사라지고, 다시 클릭하면 1.5초를 처음부터 센다. 들어오고 나갈 때 페이드하고, 동작 줄이기(reduced motion) 설정을 따른다.
- 문구는 `en.ts`/`ko.ts`에 둔다. 캡처와 녹화 문구를 따로 둔다. (예: "여기에는 캡처할 창이 없어요" / "No window to capture here")
- 영역 모드로 바꾸거나 오버레이를 닫으면 알림도 바로 사라진다.

### 3. 커서 (D. Tilted Sticker)

- `globals.css`의 `cursor-camera`, `cursor-record`를 D 시안으로 바꾸고 `cursor-blocked`를 추가한다. 세 커서 모두 32px에 2x `image-set`을 두고, 클릭 지점은 가운데(16 16)다. 대체 커서는 camera·record가 `pointer`, blocked가 `not-allowed`다.
  - 캡처: -8° 기운 스퀘어클(rx 10), 연보라→브랜드 보라→하늘 그라데이션, 흰 테두리, 셔터 날개 4개.
  - 녹화: 같은 모양에 분홍→빨강 그라데이션, 흰 녹화 점.
  - 선택 불가: +8° 기운 회색(`#6b6f7d`) 스퀘어클 안에 흰 금지 표시.
- `CaptureApp`은 창 모드에서 아무 창도 고르지 않았고 마우스 아래에 창이 없으면 `cursor-blocked`를 쓴다. `refreshCursor`가 필요한지는 기존 패턴을 따른다.

## 남은 결정(구현자 몫)

- 알림의 정확한 간격과 글자 크기는 툴바에 맞춘다.
- 마우스를 움직일 때마다 `windowAt`을 다시 부를지, 이미 계산한 hover 값을 재사용할지.

## 검증

- `cargo test --lib`, `yarn test`, `yarn typecheck`, `yarn lint`
- `yarn tauri dev`로 띄워 라이트/다크, 한국어/English, 캡처/녹화 각각에서 겹친 창의 모서리, 바탕화면 클릭 알림, 세 커서를 직접 확인한다.
